# Comparer les stratégies décisionnelles dans le radar scientifique

Trois méthodes expérimentales, réservées aux profils génératifs locaux dont l’adresse permet de résoudre Responses sur le même hôte (y compris Chat) : logprobs seuls, hybride sans zoom, hybride avec zoom. Le zoom exige le transport Chat natif ou Responses ; les profils Chat Completions ne peuvent pas mesurer cette variante. Même modèle, mêmes batteries A/B/C (3 passages) et D/E. Les anciens essais S0–S5 (flèches dirigées et graphe) restent archivés mais ne sont plus lancés ni comptabilisés dans le radar des dessins d’observation. La compréhension biologique est mesurée sur les attendus des dessins A/B/C et R1/R2/R3. Les traits de rappel D/E restent évalués par leur destination, sans pointe ni sens exigés. Le nouveau radar comporte sept axes ; les scores historiques à neuf axes ne sont pas directement comparables. Les décisions rapides sont comptées comme des observations non validées ; les notes restent nulles lorsqu'une revue humaine est requise. Les sondes, critères rapides, total des critères et indisponibilité sont archivés dans le rapport, sans images ni clés. Les durées sont applicatives (pas de durée native partielle). Une incompatibilité technique ne compte pas comme réussite hybride. Le radar biologique textuel n'est pas modifié. Le seuil de 95 % est expérimental, non calibré. Comparer les stratégies avec le même profil et la même configuration de thinking ; les sondes demandent toujours Thinking OFF. Aucun résultat de précision réel sur Bionic n'est fourni par la CI.
