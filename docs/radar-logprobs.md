# Comparer les stratégies décisionnelles dans le radar scientifique

Trois méthodes expérimentales, réservées aux profils génératifs Responses locaux : logprobs seuls, hybride sans zoom, hybride avec zoom. Même modèle, mêmes batteries A/B/C (3 passages), D/E et S0–S5. Le graphe indépendant reste baseline et ne doit pas être interprété comme une mesure du zoom ou des logprobs. Les décisions rapides sont comptées comme des observations non validées ; les notes restent nulles lorsqu'une revue humaine est requise. Les sondes, critères rapides, total des critères et indisponibilité sont archivés dans le rapport, sans images ni clés. Les durées sont applicatives (pas de durée native partielle). Une incompatibilité technique ne compte pas comme réussite hybride. Le radar biologique textuel n'est pas modifié. Le seuil de 95 % est expérimental, non calibré. Comparer les stratégies avec le même profil et la même configuration de thinking ; les sondes demandent toujours Thinking OFF. Aucun résultat de précision réel sur Bionic n'est fourni par la CI.
