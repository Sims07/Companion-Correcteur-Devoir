# Companion Correcteur Devoir

Application de correction assistée de copies manuscrites pour les enseignants en biologie, avec une priorité à la confidentialité et à l'exécution locale via Ollama.

## Principes

- Les copies et leurs images restent locales par défaut.
- L'enseignant configure le barème et valide les propositions de correction.
- Les réponses ambiguës ou illisibles sont signalées pour demander une précision.
- Les notes et justifications restent traçables et modifiables.

## Statut

Projet en initialisation. Les fonctionnalités ne sont pas encore implémentées.
